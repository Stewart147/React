This React project is another iteration of the password-gen project, it generates a password up to 100
characters long, can have letters uppercase or lowercase, has toggle buttons if you want to add numbers or
special characters into the generated password. Extra features in this iteration is an icon displaying password strength.
Another toggle button to extract similar letters and numbers that can be confusing such as 0,O, I ,1 ,l etc.
Also has an option to copy password.
To view this project type in the following commands in the terminal:
cd password-gen
npm run dev
To access localhost server address: http://localhost:5173
