This React project is another iteration of the JobForm project. Job title and Status can be entered and categories can
be selected. Maximum amount of categories that can be selected is 3 out of a possible 5. Improved styling has been
added along with error message if a field is not added. Also a clear button is used to clear all categories.
The project can be viewed by typing in the command npm start in the terminal.
Access to the localhost server address: http://localhost:3000
