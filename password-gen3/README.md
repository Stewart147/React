This is a React project which is an iteration of the password-gen project. It allows you to generate a password of
maximum length 100 characters. Characters can be letters lowercase or uppercase and has toggle buttons to add 
special characters or numbers into the password. An icon displays password strength and has a styled copy button
to copy password. A copied message is displayed for a short duration when the password is copied.
To view this project, type the following commands into the terminal:
cd password-gen
npm run dev
To access localhost server address: http://localhost:5173
