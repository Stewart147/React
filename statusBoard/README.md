This React project creates a statusBoard template with status- completed - in-progress - failed.
The status categories have a layout of 3 columns. Each category has an add button to add tickets to the selected ticket
category and a counter is used to display the number of tickets per category. A reset button is used to reset all ticket
counts to zero. This project can be viewed by typing the command npm start into the terminal and accessing the localhost
server address at: http://localhost:3000
