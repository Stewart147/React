This React project is an iteration of the password-gen project. It generates a password with a maximum of 100
characters, letters uppercase or lowercase, has buttons to add special characters or numbers of which one must be added to letters
or an error prompt will be displayed, password strength is shown weak, medium, strong along with option to exclude
similar characters. Extra features are copy password with copied message and keyboard options for generating password. 
Also this iteration allows you to create multiple passwords and copy all passwords.
To view this project, type in the following commands in the terminal:
cd password-gen
npm run dev
To access localhost server address: http://localhost:5173
