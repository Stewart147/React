This React project is another iteration of the invest-calc project. It has a neat input for changing investment options
such as how many years, investment return percentages. PDF Format report can be added along with the option to save the report.
A graph is also added to show various investment scenarios. The project can be viewed by typing in the following commands in the
terminal:
cd invest-project
npm run dev
Access to the localhost server address: http://localhost:5173
