This React project is an iteration of the password-gen project, it will generate a password up to 100
characters which can contain letters uppercase or lowercase. Toggle buttons for numbers or special characters
are used to add in numbers and special characters if you want to.
An extra feature of this iteration is an icon bar which displays how good your password is from weak to strong.
This project can be viewed by typing the following commands into the terminal:
cd password-gen
npm run dev
You can access the localhost server address at: http://localhost:5173
