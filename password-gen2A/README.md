This React project is another iteration of the password-gen project. It creates a password of maximum length 100
characters, of which can be lowercase or uppercase letters, the password must include numbers or special characters
which can be selected by toggle buttons. If no numbers or special characters are selected an error message is displayed prompting 
you to do so. A password strength icon bar displays the strength of the password generated. This iteration also adds in
a copy feature and displays it has been copied. Also adds feature to add password via keyboard keys.
To view this project type in the following commands in terminal:
cd password-gen
npm run dev
To access the localhost server address: http://localhost:5173
