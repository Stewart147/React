This React project is an iteration of the jobForm project, you can give the job a Name and Status and select 3
categories out of 5. The project will not allow you to select more than 5 categories. A button can be clicked to clear all
selected categories. When a category is selected it is styled to display colour green. Asearch feature is also incorporated
into this project.
To view this project type in the command npm start into the terminal.
Access to the localhost server address: http://localhost:3000
