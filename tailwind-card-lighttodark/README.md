This React project is another iteration of the tailwind-card project. It displays a tailwind styled card
and also adds functionality where you can add images and content to the display via an add button.
A light/dark toggle button is also introduced so you have option to view webpage in light or dark mode.
To view this project type in the following commands to the terminal:
cd my-project
npm run dev

To access the localhost server address: http://localhost:5173
