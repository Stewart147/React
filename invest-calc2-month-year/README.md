This React project is another iteration of the invest-calc project. It has all the styles of previous iteration
along with output calculations for investments, however this project adds a button to toggle between monthly and yearly projections.
A graph is also added to demonstrate monthly or yearly projection forecasts based on your preference. This project can be viewed
by typing into the terminal the following commands:
cd invest-project
npm run dev
Can be accessed via the localhost server address http://localhost:5173
